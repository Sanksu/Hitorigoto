# Hitorigoto: 领域术语表

本文档定义 Hitorigoto 项目中的核心领域术语及其精确含义，供开发者和贡献者参考。

## Post（动态）

一条即时发表的轻量状态更新，类似微博/tweet。无标题、无分类/标签。
- **内容**: Markdown 原文 + 自动渲染的 HTML
- **元数据**: 操作系统、浏览器（来自 User-Agent 解析）。核心功能: 知道发布者用什么设备发的是 Hitorigoto 的魅力之一。未来可扩展客户端信息（设备型号、屏幕分辨率等）
- **时间**: 创建时间、最后更新时间
- **编辑**: 修改内容后重新渲染 HTML，记录 `updatedAt`。前端可选择是否显示"修改于"标记
- **删除**: 物理删除，无软删除机制
- **状态枚举** (`status`): `published`（默认）| `hidden`（归档，对公开 API 不可见）| `pinned`（置顶）
  - `published`: 公开 API 返回（默认）
  - `hidden`: 公开 API 不返回，单条 ID 查询可获取
  - `pinned`: 公开 API 返回，列表优先显示
- **隐藏**: 对公开 API 不可见，管理员在后台仍可查看和管理
- **置顶**: 置顶动态在列表中优先显示（按置顶时间而非创建时间排序）

## 前端 Widget（嵌入组件）

一个独立的、可分发的前端 JS 组件，可连接任何兼容的 Hitorigoto 后端。
- **入口**: `Hitorigoto.init({ serverURL, ... })`
- **多实例**: 同一页面可嵌入多个独立实例（不同 `el` 选择器）
- **可定制**: CSS 变量 + `theme` 参数双通道覆盖样式
- **与服务端的关系**: API 契约定义良好的松耦合关系，非绑定关系

## Admin（管理员）

Hitorigoto 的管理员身份。每个站点只使用一种认证模式，上线后不可切换。
- **与 Waline 的关系**: 仅共用 `wl_users` 表做管理员认证。Hitorigoto 不读 Waline 的其他表（评论、页面等），两套数据互相独立。

### 认证模式

| 模式 | 说明 | 用户表 |
|---|---|---|
| `waline` | 与 Waline 共用管理员账号，适合已有 Waline 部署的用户 | `wl_users` |
| `hitorigoto` | 独立管理，使用 Hitorigoto 自有的 `hg_admin` 表 | `hg_admin` |

> **已接受的张力**: 领域上认证模式是部署时决策，但实现允许通过 Header/查询参数运行时覆盖。保留灵活性以支持调试和迁移场景。

### 单一管理员原则

Hitorigoto 始终只有一个管理员账号。所有动态共享同一管理员头像和显示名。无多发布者模型。

- **数据库**: `hg_admin` 表未强制单行限制（领域逻辑约束，非数据库约束）。
- **前台身份**: 所有动态共用第一个管理员（按 `id` 排序）的头像和显示名。
- **后台访问**: 多个管理员账号均可登录管理后台（如果存在多条记录）。

### 身份验证

无状态 Base64 Token：`base64(email:password)`，每次请求实时查库 + bcrypt 验证。
- **设计取舍**: 每请求查库 bcrypt 验证，放弃缓存/JWT。因为 Hitorigoto 是低频管理工具，不需要优化。
